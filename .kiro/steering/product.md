# force.gg — プロダクト概要

force.gg は日本語対応の League of Legends 戦績・統計 Web アプリ＆デスクトップアプリ。

**差別化ポイント**: 日本語 UI × AI コーチング（Claude API）× プロシーンスケジュール表示を一つのサービスで提供。

## 主要機能
- チャンピオン一覧（日本語名・ロールフィルター・検索）
- サモナー検索・戦績表示
- チャンピオン統計・勝率表示
- プロシーンスケジュール（LJL / LCK / LCS / LEC / LPL / CBLOL / LCP / PCS）
- AI コーチング（Anthropic Claude API）
- デスクトップオーバーレイアプリ（Electron）— LCU API でリアルタイム統計表示
- プレミアムサブスクリプション（月額 ¥980）via Stripe

## ターゲットユーザー
母国語で戦績・ビルド・コーチングを利用したい日本人 LoL プレイヤー。

## 収益化
- Google AdSense（Web 広告・無料プラン）
- Stripe サブスクリプション（Web + デスクトップ プレミアム機能）
